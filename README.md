# CROWN オーナーズ ビジュアルガイド

トヨタ クラウン（セダン／ハイブリッド車）のオーナーズマニュアルを、
図の上から視覚的にたどれるようにした静的サイトです。

気になるスイッチにカーソルを合わせるとその部分が拡大し、クリックすると説明が読めます。

## 収録コンテンツ

| 画面 | 対応する OM ページ | 収録数 |
| --- | --- | --- |
| [運転席まわりスイッチ](cockpit.html) | P4・P5 | 25（A–R の 18 ＋ ステアリング 7） |
| [エアコン操作パネル](climate.html) | P6 | 12（A–L） |
| [コンビメーターの警告灯](meter.html) | P7 | 29 |

## 操作

| 操作 | 動き |
| --- | --- |
| ホバー（タッチ端末はタップ） | その部分がルーペで拡大表示される |
| クリック | 名称・注意事項・説明が右のパネルに表示される |
| 一覧から選択 | 図と一覧は双方向に連動する |
| `Tab` / `Enter` / `Space` / `Esc` | キーボードだけでも操作できる |

## 動かしかた

ビルド不要です。ファイルをそのままブラウザで開けば動きます。
ローカルサーバーで確認する場合は、リポジトリ直下で次のいずれかを実行してください。

```bash
python -m http.server 8000
```

```bash
npx --yes serve .
```

## 技術構成

- 素の HTML / CSS / JavaScript のみ。ビルドツール・フレームワーク・外部 CDN に依存しません。
- 図版はすべてインライン SVG。拡大してもぼやけず、ホットスポットを図形座標で厳密に一致させられます。
- フォントは OS 標準の日本語明朝／ゴシックをフォントスタックで指定しています。

```
.
├── index.html          トップ
├── cockpit.html        ① 運転席まわりスイッチ
├── climate.html        ② エアコン操作パネル
├── meter.html          ③ コンビメーターの警告灯
├── assets/
│   ├── css/style.css   デザイントークン・レイアウト
│   └── js/
│       ├── explorer.js       ホバー拡大／クリック説明の共通処理
│       ├── data-cockpit.js   ① のデータ
│       ├── data-climate.js   ② のデータ
│       └── data-meter.js     ③ のデータ
├── CLAUDE.md           開発時のルール（Git 運用ルールを含む）
└── README.md
```
